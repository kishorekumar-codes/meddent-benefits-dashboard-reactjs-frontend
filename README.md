# MedDent Benefits Accelerator

A modern **frontend dashboard** designed to track and automate patient insurance benefit verifications for **RCM** (Revenue Cycle Management) workflows in real time.

## Key Features

- **Workflow Tracker**: Monitor verification steps in real time (e.g., Data Validation, Carrier Verification)—supporting dynamic workflow pipelines with precise step completion times.
- **Orchestrator Controls**: Easily Start, Pause, Restart, or Stop the automation pipeline.
- **Patient Queue**: View queued patients, their current status, and recent updates at a glance.
- **Live Analytics**: Track real-time progress percentages, estimated remaining time, and key performance metrics.

## Tech Stack

- **Frontend Framework**: React
- **Build Tool**: Vite
- **Styling**: CSS
