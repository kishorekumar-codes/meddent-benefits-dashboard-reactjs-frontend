# MedDent Benefits Accelerator

A modern **frontend dashboard** designed to monitor and automate patient insurance benefit verification within **RCM (Revenue Cycle Management)** workflows.

## Key Features

* **Workflow Tracker**: Monitor verification steps in real time, including Data Validation and Carrier Verification, with support for dynamic workflow pipelines and step completion tracking.
* **Orchestrator Controls**: Start, pause, restart, or stop the automation pipeline.
* **Patient Queue**: View queued patients, their current status, and recent updates at a glance.
* **Live Analytics**: Monitor real-time progress, estimated remaining time, and key performance metrics.

## Tech Stack

* **Frontend Framework**: React
* **Build Tool**: Vite
* **Styling**: CSS
* **Icons**: Lucide React

## How to Run the Project

### 1. Clone the Repository

```
git clone https://github.com/kishorekumar-codes/meddent-benefits-dashboard-reactjs-frontend.git
```

### 2. Navigate to the Project

```
cd meddent-benefits-dashboard-reactjs-frontend
```

### 3. Install Dependencies

```
yarn install
```

### 4. Start the Development Server

```
yarn dev
```
